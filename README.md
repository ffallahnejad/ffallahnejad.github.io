# Fatemeh Fallahnejad - Portfolio

This repository publishes the portfolio at https://ffallahnejad.github.io/.

## Edit the wording

1. Open `index.html` on GitHub.
2. Click the pencil icon labeled **Edit this file**.
3. Change only the wording between the HTML tags.
4. Click **Commit changes** and commit directly to `main`.
5. Wait about one minute, then refresh the live website.

## Edit the colors or spacing

Open `styles.css`, click the pencil icon, make the change, and commit it to
`main`. The baby-blue color values are listed at the top of the file.

The paper manuscript is intentionally not included or linked.
